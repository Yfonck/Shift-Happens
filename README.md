# Shift Happens 🐹🌀

Un hámster. Dos realidades. Un solo botón.

**Shift Happens** es un endless runner donde un hámster corre sin parar por un corredor que se retuerce entre dos dimensiones superpuestas. Los obstáculos existen en una sola realidad: si estás en la capa correcta, chocas; si no, los atraviesas como un fantasma. Tu única herramienta es la tecla **Shift**.

Creado para **Game Off 2026** (tema: *SHIFT*).

## 🎮 Controles

- **Mantén Shift** → cambia a la realidad A (cálida)
- **Suelta Shift** → vuelve a la realidad B (fría)
- **R o clic** → reiniciar tras un choque

## ✨ Características

- 🐹 Un hámster valiente (y un poco confundido)
- 🌗 Dos realidades con paletas y obstáculos propios
- ⌨️ Diseño de un solo botón: fácil de aprender, difícil de dominar
- 🏆 Récord local guardado
- 🌐 Jugable directamente en el navegador

## 🛠️ Stack

- [Flutter](https://flutter.dev/)
- [Flame](https://flame-engine.org/) (motor de juegos 2D)
- `flame_audio` para sonido
